# 🛒 বাজার দর (BazarDor) — নিত্যপ্রয়োজনীয় পণ্যের বাজারদর

> **বাজার দর — প্রয়োজনীয় পণ্যের দাম এক নজরে।**  
> চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ ও মসলার আজকের বাজারমূল্য — বাজারভিত্তিক বিস্তারিত, গড়, সর্বনিম্ন-সর্বাধিক এবং দামের পরিবর্তন এক জায়গায়।

---

## 📌 প্রোজেক্ট পরিচিতি (Project Overview)

**বাজার দর (BazarDor)** হলো বাংলাদেশের সাধারণ মানুষের সুবিধার্থে তৈরি একটি আধুনিক ওয়েব অ্যাপ্লিকেশন। বাজারে বিভিন্ন প্রয়োজনীয় পণ্যের ওঠানামা করা দামের সঠিক তথ্য, বিভিন্ন বিভাগীয় বাজারগুলোর দামের পার্থক্য এবং দৈনিক ট্রেন্ড ট্র্যাক করার জন্য এটি তৈরি করা হয়েছে।

## 🛠️ ব্যবহৃত প্রযুক্তি (Technologies Used)

| প্রযুক্তি | ব্যবহারের উদ্দেশ্য |
| :--- | :--- |
| **Next.js 16 (App Router)** | আধুনিক React ফ্রেমওয়ার্ক, সার্ভার কম্পোনেন্ট, অপ্টিমাইজড পেজ রাউটিং |
| **React 19** | ইন্টারঅ্যাক্টিভ ইউজার ইন্টারফেস ও কম্পোনেন্ট লাইব্রেরি |
| **TypeScript** | টাইপ-সেফ কোডবেস এবং স্কেলেবল ডেভেলপমেন্ট |
| **Tailwind CSS 4 & DaisyUI 5** | আধুনিক রেসপন্সিভ ডিজাইন ও কম্পোনেন্ট স্টাইলিং |
| **BetterAuth** | নিরাপদ ইউজার অথেনটিকেশন (ইমেইল/পাসওয়ার্ড, গুগল ও গিটহাব ও-অথ) |
| **MongoDB Atlas** | ক্লাউড ডাটাবেস পারসিস্টেন্স (User, Session, Account) |
| **react-hot-toast** | ইউজার ফ্রেন্ডলি নোটিফিকেশন ও অ্যালার্ট |

## ✨ ৫টি মূল বৈশিষ্ট্য (5 Key Features)

1. **📊 রিয়েলটাইম প্রাইস টিকার ও মার্কেট ট্রেন্ডস (Price Ticker & Market Trends):**
   - ওয়েবসাইটের শীর্ষে ইনফিনিট স্ক্রোলিং প্রাইস টিকার (Marquee), যা পণ্যের আজকের দাম এবং শতকরা পরিবর্তন (▲ / ▼) প্রদর্শন করে।
   - হোম পেজে শীর্ষ দাম বৃদ্ধি পাওয়া (`আজ দাম বেড়েছে ▲`) এবং দাম কমে যাওয়া (`আজ দাম কমেছে ▼`) পণ্যের পৃথক সেকশন।

2. **🏪 বিভাগ ও বাজারভিত্তিক বিস্তারিত তথ্য (Market-wise Detailed Pricing):**
   - প্রটেক্টেড ডিটেইল পেজে ঢাকা, চট্টগ্রাম, রাজশাহী, ময়মনসিংহ, খুলনা, সিলেটসহ বিভিন্ন বিভাগের বাজারের সর্বনিম্ন ও সর্বোচ্চ দামের নির্ভুল তুলনামূলক তালিকা।
   - সর্বনিম্ন, গড় ও সর্বোচ্চ মূল্যের সংক্ষিপ্ত কার্ড।

3. **🔍 স্মার্ট ক্যাটাগরি ফিল্টারিং ও সঠিক বাংলা সংখ্যায় সর্টিং (Category & Numeric Sorting):**
   - চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ এবং মসলা ক্যাটাগরি অনুযায়ী পণ্য দেখার সুবিধা।
   - দাম অনুযায়ী সাজানোর ড্রপডাউন (`ডিফল্ট`, `দাম: কম থেকে বেশি`, `দাম: বেশি থেকে কম`) যা সম্পূর্ণ নির্ভুলভাবে কাজ করে।

4. **🔐 আধুনিক বহু-পদ্ধতির প্রমাণীকরণ (Modern Authentication with MongoDB):**
   - BetterAuth এর মাধ্যমে নিরাপদ ইমেইল-পাসওয়ার্ড রেজিস্টার ও লগইন।
   - এক ক্লিকে গুগল (`Google`) ও গিটহাব (`GitHub`) সোশ্যাল লগইন।
   - সমস্ত ইউজার ও সেশন তথ্য সুরক্ষিতভাবে MongoDB ক্লাউড ডাটাবেসে সংরক্ষিত।

5. **👤 প্রোফাইল ম্যানেজমেন্ট ও তথ্য আপডেট (Profile & User Info Update):**
   - লগইন করা ব্যবহারকারীদের জন্য পার্সোনালাইজড প্রোফাইল পেজ।
   - BetterAuth এর `updateUser` API ব্যবহার করে সহজেই নাম পরিবর্তনের সুবিধা।
   - ক্যাটাগরি ও প্রোডাক্ট ডেটায় স্কেলিটন লোডিং এবং সুন্দর ৪০৪ পেজ।

## 🚀 লোকাল মেশিনে চালানোর নিয়ম (Getting Started)

### ১. ক্লোন ও ডিপেন্ডেন্সি ইনস্টল:
```bash
git clone <your-repo-link>
cd bazar_dor_app
npm install
```

### ২. এনভায়রনমেন্ট ভেরিয়েবল সেটআপ:
প্রোজেক্টের রুট ডিরেক্টরিতে একটি `.env` ফাইল তৈরি করুন:
```env
BETTER_AUTH_SECRET=bazar-dor-secret-key-for-auth-2026
BETTER_AUTH_URL=http://localhost:3000
MONGODB_URI=your_mongodb_connection_uri
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
GITHUB_CLIENT_ID=your_github_client_id
GITHUB_CLIENT_SECRET=your_github_client_secret
```

### ৩. রান করুন:
```bash
# ডেভেলপমেন্ট মোড
npm run dev

# প্রোডাকশন বিল্ড ও রান
npm run build
npm start
```
ব্রাউজারে ওপেন করুন: [http://localhost:3000](http://localhost:3000)
